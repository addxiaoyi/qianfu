Mode A

官方 API

适合你当前这套付费版。XPay 可以直接发起支付宝当面付和微信 Native 下单，并接官方异步回调自动入账。

Mode B

多租户中台

每个项目拥有自己的 tenantKey、accessToken、callbackSecret 和支付方式，不再把所有业务混在同一套订单里。

Mode C

个人码监听

当官方接口不可用时，仍然可以保留个人码监听中间层，把到账事件推给 Node 再桥接回 XPay 完成业务回调。
