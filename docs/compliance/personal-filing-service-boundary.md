# 个人备案模式服务边界

本文档记录千服联灯当前按个人备案场景收口后的产品边界，不代表行政机关对主体、内容或运营方式的正式认定。

## 已关闭

- 支付下单、支付回调、充值、钱包余额和余额流水入口。
- 收费上架、月租/季付/年付推荐权重和任何自动扣款。
- 玩家商城、商品订单、数字商品交付、卖家中心和交易争议流程。
- 推广任务、推广绑定、奖励领取、现金/余额奖励和相关管理入口。

历史订单、支付流水和审计记录不在本次变更中删除，以便保留必要的账务与审计证据；关闭后不再提供新的交易写入或支付回调处理。

## 保留

- Minecraft 服务器公开发现、资料展示、状态展示和免费发布审核。
- 账号注册、登录、个人资料、邮箱验证和安全设置。
- 新闻公告、内容审核、举报、工单和站点规则。
- 头像/新闻图片等必要内容上传，继续使用既有安全校验和 R2 存储边界。

## 运营注意

- 个人备案不等于自动覆盖所有实际运营场景；上线前仍需核对主体、网站名称、服务内容、联系方式和实际数据处理方式。
- 关闭前端入口不能替代后端鉴权；任何商业接口都必须在服务端未注册或 fail closed。
- 不要在公开页面、邮件模板或管理员配置中恢复支付、收费套餐、商城交易或现金推广描述，除非重新完成主体和合规评估。
