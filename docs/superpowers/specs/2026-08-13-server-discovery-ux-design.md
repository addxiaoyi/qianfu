# 服务器发现体验设计

## 目标

让玩家从进入服务器页开始，能够快速选择找服意图、比较真实状态、查看详情，并复制地址进入游戏。

## 用户路径

`选择找服意图 -> 筛选与排序 -> 比较服务器 -> 查看详情 -> 复制地址`

## 交互设计

- 列表首屏提供“现在就玩”“多人活跃”“刚刚加入”“全部服务器”四个意图入口。
- 完整目录提供搜索、分类、平台、版本、在线状态和排序控件。
- 搜索与筛选状态写入 URL，刷新和分享链接后保持一致。
- 结果区显示当前条件摘要、结果数量和清除筛选动作。
- 服务器卡片突出真实在线状态、在线人数、版本、平台、分类、标签和状态更新时间。
- 卡片提供明确的“查看详情”主动作和独立复制地址按钮；无地址、无封面、状态未知时显示真实的空缺状态。
- 详情首屏前置状态、人数、版本、平台、玩法标签和复制地址主按钮，技术规格和规则信息继续放在后续区域。
- 移动端复用同一信息优先级，并保留底部复制地址操作栏。

## 数据边界

只使用公开服务器接口已有字段：`online`、`playersOnline`、`playersMax`、`lastUpdated`、`updated_at`、`platform`、`category`、`supported_versions`、`tags`、`ip`、`activity`。不展示虚构评分、热度或推荐理由。

## 验收标准

- 桌面服务器列表最多三列，移动端单列。
- 四个意图入口请求正确的排序或在线条件。
- URL 筛选参数可以初始化界面，并在用户操作后同步更新。
- 卡片与详情使用同一套状态、人数、版本和标签格式化逻辑。
- 复制地址成功、失败、无地址三种状态均有明确反馈。
- 加载、接口错误、空结果和无封面状态不出现空白区域。
- 不新增商业能力或支付相关入口。
