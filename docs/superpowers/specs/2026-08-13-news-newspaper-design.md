# 新闻报纸长篇阅读设计

## 目标

把公开新闻页从普通信息列表改成中文报纸式长篇阅读页面。第一条已发布新闻作为头版主文，其余新闻作为报纸短讯；继续使用现有 `/announcements` 接口，不新增数据库字段、详情路由或后台编辑流程。

## 版式

- 报头：刊名、日期、期号、编辑部标记和当前新闻总数。
- 头版：主标题、导语、分类、更新时间、预计阅读时间和正文。
- 长文正文：窄栏宽度、首段大首字、段落间距、图片独立图注、引用段和分隔小节；普通换行继续保留。
- 目录栏：桌面端位于正文右侧，显示“头版主文”和其他短讯；移动端放到主文之前，避免横向滚动。
- 短讯栏：按更新时间倒序，使用编号、分类、日期、标题、摘要和站内链接。
- 状态：继续使用现有加载、错误、空数据和图片失败状态。

## 内容边界

- 只使用现有 `Announcement` 字段：`title`、`message`、`tone`、`updatedAt`、`linkLabel`、`linkPath`。
- 不把新闻正文当作 HTML 渲染；图片仍通过现有安全 Markdown 解析器展示。
- 不加入支付、钱包、商城、推广等商业能力入口。

## 响应式验收

- 桌面端：报头和头版正文为宽布局，正文与目录形成主次分栏。
- 移动端：单列，标题与正文不溢出，目录和短讯按阅读顺序堆叠。
- 低内容量：只有一条新闻时仍完整显示头版和目录，不出现空白栏或错误统计。
