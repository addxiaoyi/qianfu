# Remotion 首次打开入场动画设计

## 目标

为千服联灯增加一段全站首次打开入场动画，采用 Minecraft 像素世界中的“飞越方块群”视觉方向。动画使用 Remotion 的 React 时间轴在浏览器内播放，不生成视频文件，不依赖外部图片、音频或网络资源。

## 用户体验

- 仅在当前浏览器会话首次打开时播放一次。
- 路由切换和刷新不重复播放。
- 总时长 1.2 秒，60fps。
- 0-0.25 秒：夜空与体素地形从暗处显现。
- 0.25-0.8 秒：镜头向前飞越方块群，方块产生轻微纵深位移。
- 0.65-1.05 秒：千服联灯标志与 `SERVER DISCOVERY` 出现。
- 1.05-1.2 秒：场景向下收拢，真实页面接管。
- 右上角提供可聚焦的跳过按钮，支持 `Escape`。
- `prefers-reduced-motion: reduce` 下禁用位移和粒子，只保留极短淡入。
- `sessionStorage` 记录会话内已完成的入场动画。

## 结构

### EntryAnimationGate

入口门控组件放在 `App.tsx` 的应用壳层上方，覆盖所有路由但不改变路由配置。它负责：

1. 读取并写入会话播放标记。
2. 判断减少动态效果和浏览器环境。
3. 挂载 Remotion Player 与跳过按钮。
4. 在播放完成、跳过或错误时卸载覆盖层。

真实路由内容在覆盖层下方同时渲染，动画结束后只移除覆盖层，不重新挂载页面或触发额外数据请求。

### MinecraftFlightComposition

Composition 是纯时间轴组件，使用 Remotion 的 `AbsoluteFill`、`useCurrentFrame`、`interpolate` 和 `spring`：

- 深色天空与静态星点提供背景层。
- 体素方块使用固定尺寸的 CSS 图形，按帧计算透明度、位移和缩放。
- 标志和副标题在中后段通过 spring 出现。
- 结束帧将场景透明度和位置交给门控组件完成退出。

使用 `@remotion/player` 将 Composition 内嵌到 React 页面；项目只增加浏览器播放所需依赖，不引入 Remotion CLI、渲染服务或视频资源。

## 错误处理与可访问性

- Remotion Player 加载、渲染或播放失败时，入口门控立即放行真实页面。
- `sessionStorage` 不可用时不阻塞页面，只按当前挂载周期播放一次。
- 跳过按钮使用原生 `button`、明确标签和可见焦点样式。
- 动画层在退出前保持 `aria-hidden`，不截断底层页面的键盘流程；跳过后从 DOM 移除。
- 不使用外部网络资源、音频、自动播放媒体或需要用户权限的能力。

## 验收与测试

### 单元测试

- 首次打开会挂载入口动画。
- 会话标记存在时不挂载入口动画。
- 播放完成和跳过都会写入会话标记并卸载覆盖层。
- `prefers-reduced-motion` 和异常存储行为不会阻塞页面。

### 浏览器验收

- 桌面首次打开可看到完整 B2 动画。
- 刷新同一标签页不重复播放。
- 点击跳过和按 `Escape` 都立即显示可交互页面。
- `390x844` 移动端无横向溢出和遮挡。
- 页面控制台无错误，真实路由数据请求只发生一次。

### 发布检查

- `npm --prefix qianfu-liandeng run build` 通过。
- 针对入口门控和 Remotion Composition 的 Vitest 契约测试通过。
- 生产静态资源上传到独立 release 后，通过 Nginx 原子切换。
- 公网入口、入口 bundle 和移动端截图完成抽样验证。

## 范围外

- 不为每次路由切换增加过渡动画。
- 不制作或上传独立 MP4/WebM 文件。
- 不在管理员后台增加动画配置项。
- 不改变现有首页内容、接口请求、认证和路由行为。
