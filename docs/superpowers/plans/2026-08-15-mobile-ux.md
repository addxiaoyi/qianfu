# Mobile Core UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the mobile home, discovery, server detail, editor, and account routes feel like one coherent touch-first application without changing desktop routes or backend contracts.

**Architecture:** Keep `App.tsx` as the mobile route boundary and `MobileLayout` as the only mobile scroll root. Add one small accessible mobile selection-sheet primitive, then update each mobile page to use stable first-screen spacing, safe-area-aware actions, and explicit loading/empty/error states. URL-backed discovery filters and existing request functions remain the source of truth.

**Tech Stack:** React 19, TypeScript, React Router, TanStack Query, Tailwind CSS, lucide-react, Vitest.

interface MobileSelectOption<T extends string> {

  label: string;

  title: string;
  value: T;
