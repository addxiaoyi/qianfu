# 移动端 UX 修复记录

## 已修复
- 关闭移动端全局浮窗设置入口，避免遮挡表单。
- 修正移动端页面滚动容器，进入新路由时自动回到顶部。
- 阻止表单页被原生下拉刷新误触。
- 新建工单页、发布页、资料编辑页、支付页隐藏底部导航，减少提交区遮挡。
- 发布页移动端操作栏改为更适合小屏的布局。
- 登录、注册、找回密码页收紧了移动端外层留白，减少首屏空白。
- 注册页密码与确认密码改为移动端单列，避免窄屏双栏过挤。
- 找回密码页步骤条在移动端仅保留数字进度，避免标签换行挤压。
